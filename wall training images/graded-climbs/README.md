# Graded indoor gym-wall photographs

106 indoor bouldering problems on The A's spray wall in Minneapolis, MN. Each problem has one JPEG showing the wall with the selected holds outlined by the source. The images are embedded JPEGs extracted directly from the [gym's guidebook, v.15](https://www.aclimbing.com/s/_-The-A-Pokedex-v15-small.pdf), at their original embedded resolution. The grade is in the filename's directory and in `labels.csv`. The guidebook's page captions are outside the JPEG crops.

Grades from the guidebook: V0 (8), V1 (13), V2 (16), V3 (17), V4 (15), V5 (9), V6 (11), V7 (7), V8 (3), V9 (4), V10 (2), V11 (1).

The guidebook contains repeated routes and two entries without numeric grades. This collection uses one image per included problem. The Machoke image was omitted because it contains a visible V7 badge inside the picture.

The photographs come from one wall. Wall sections and base photos can repeat across problems, with different holds highlighted. Use the labels for route grading on a spray wall. For evaluation on unfamiliar walls, hold out a different gym or wall. The grade labels are from guidebook v.15 and can differ from earlier revisions.

Source attribution: The A gym and the contributors to its guidebook. See the [gym's guides page](https://www.aclimbing.com/guides). No explicit image reuse or training license was found in the guidebook or on its download page.
